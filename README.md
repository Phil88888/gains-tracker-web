# Gains Tracker – Webseite

Öffentliche Webseite der App Gains Tracker: Funktionen, Hilfe und Datenschutzerklärung.
Läuft über GitHub Pages, ohne Build-Schritt, ohne fremde Skripte oder Schriften.

- `index.html` – Startseite (Bewegung in `assets/site.js`, Gestaltung in `assets/site.css`)
- `datenschutz/index.html` – Datenschutzerklärung; Inhalt aus `docs/datenschutz.md` im App-Projekt
- `assets/screens/` – Store-Bilder aus `docs/store-bilder/final/de` (600 px breit, JPEG)

Farben: Charcoal Black `#171717`, Forest Green `#06110C`, Crimson Red `#A31C1B`.
